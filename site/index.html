04 / TRUST BOUNDARY

Public demo and private local agent—clearly separated.

Hosting the site makes the project easy to explore. Running serve.py unlocks the machine-facing parts without pretending a remote web server could control your PC.

  • 01

    Camera frames never leave the browser.

  • 02

  • 03

05 / RUN LOCALLY

From folder to agent in three commands.

Use Python 3.9–3.12. Ollama works without an API key; Gemini and Claude can be configured later.

  1. 1

    InstallOptional gesture dependencies include MediaPipe and OpenCV.

  2. 2

    ConfigureChoose a model channel or run entirely with Ollama.

  3. 3

    ServeOpen the console on localhost:8790.

HYBRID_AGENT — SETUP
PS> cd "C:\Users\User\Desktop\HYBRID AGENT"
PS> python -m pip install -r requirements.txt
PS> python configure.py
PS> python serve.py

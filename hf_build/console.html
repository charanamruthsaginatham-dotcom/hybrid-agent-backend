Operator Access

Sign in to A.D.A

Sign in to use your own Gemini, Claude or added model — each key is yours alone. Prefer not to? Close this (ESC) and keep going with Local Ollama, which needs no account and no key.

Your password is hashed before it is stored — never written as plain text. Signing in scopes your Gemini, Claude and any custom keys to this account alone; this console never answers a visitor with someone else's key. No account yet? Use the link above to create one — it takes ten seconds.

bridge session

Your Gemini, Claude and custom keys are scoped to this account and stored only on this machine. Sign out and the console falls back to Ollama only for the next visitor.

TRACK
Launcher

Open an app

Everything opens as an https web app. WhatsApp is the exception: it opens the desktop client through whatsapp:// and only falls back to the web if the client is not installed. Sign in to add your own shortcuts — they show up first, above the built-ins.

CHECKING LOCAL BRIDGE

Desktop and system apps need the local bridge: run python serve.py and open the console from it. Without the bridge, web apps still open in a new tab. Added apps are yours alone — signed out, or on someone else's session, they are not there.

Model channels

Which model answers?

Pick the channel this console talks to and give it an API key. Signing in scopes every key to your account alone — nobody else who opens this console can use it. Keys are written to config.json on this machine and are sent only to that provider.

CHECKING LOCAL BRIDGE

No bridge, no keys: the console answers from its built-in sample replies and says so. Ollama needs no key — just ollama serve. ADD LLM connects any OpenAI-chat-completions-compatible endpoint — Mistral, Groq, OpenRouter, DeepSeek, a local llama.cpp server. You can also run python configure.py --add-llm in the terminal.

Bluetooth

Paired devices

Windows reports the radio and every device already paired with this machine. Connecting asks the operating system to bring the link up — a device that is switched off or out of range cannot be reached, and this panel says so rather than pretending.

CHECKING LOCAL BRIDGE
Radio —

Pairing a new device needs the Windows dialog, because it asks you to confirm a PIN — . In the terminal: python bluetooth.py.

Hardware

Boards, mini computers and phones

Microcontrollers over USB serial, anything on the network you have saved, and Android phones through adb. Each row shows whether it answers right now — not whether it was ever plugged in.

CHECKING LOCAL BRIDGE

Serial needs pip install pyserial. Phones need USB debugging, or wireless debugging plus adb connect <ip>. SSH is printed for you to run yourself — it asks for a password, and this console never handles one.
